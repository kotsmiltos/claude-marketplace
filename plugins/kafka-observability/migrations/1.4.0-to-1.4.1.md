# Migrate observability 1.4.0 → 1.4.1

> Severity: internal (documentation-only). Applied by `/add-kafka-observability` (upgrade mode);
> readable standalone.

## What changed

Nothing that runs. No export, signature, env-var key, event-envelope field, redaction rule, or
producer setting changed. The delta is comment wording, one test fixture string, one test label, and
two example values in the in-library `README.md`.

## Why

The vendored copy had been reworded in place while `VERSION` stayed at 1.4.0, so the toolkit's
"1.4.0" and a downstream project's "1.4.0" were no longer the same bytes. The marker exists to answer
"which copy is this?" — a patch bump restores that answer. There is no behavioural motivation and
none is implied.

## Library replacement

The vendored `src/observability/*` is replaced wholesale (verbatim copy from the plugin). No files
were added or removed. The suite is unchanged at 109 tests.

**No transforms.** Nothing in a consumer project needs to change: the upgrade is the file copy plus
the `VERSION` write. A project that skips this release is functionally identical to one that takes it
— take it when convenient, so the next real upgrade starts from a known copy.

## Manual follow-ups

None.
