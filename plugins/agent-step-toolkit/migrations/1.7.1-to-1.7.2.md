# Migrate agent-step 1.7.1 → 1.7.2

> Severity: internal (behavior fixes inside the library; no API change). Applied by
> `/pull-library`; readable standalone.

## What changed

Two runtime fixes aligning the runner with its documented contract — nothing removed, no
signature changed, no project-side transforms:

- **Delegate stream timer starts after connect.** `runDelegate` previously created both
  `AbortSignal.timeout` signals at entry, so a slow thread-creation call ate into the streaming
  budget: with `connectTimeoutMs: 10_000` / `timeoutMs: 20_000`, an 8s connect left only ~12s of
  streaming. The stream signal is now created only after the connect phase returns, so `timeoutMs`
  covers exactly the run + streaming phase, as documented.
- **Missing state schema throws at construction.** `buildAgentStepTool` called with neither
  `stateSchema` nor the deprecated `stateAnnotation` previously threw only on the first tool call;
  it now throws when the tool is built (the 1.7.0-documented behavior), so a miswired tool fails
  at startup instead of mid-conversation.
- `state.ts` `errorCount` doc-comment corrected (host-listed `backendFailureCodes` verdicts also
  increment; the counter resets on any batch not ending in a backend failure).

## Library replacement

`/pull-library` replaces `src/agent-step/*` wholesale (verbatim copy from the toolkit) — that
replacement IS the whole upgrade. The library test suite grows 91 → 94 (one runner
construction-validation test, two handoff delegate-timeout tests).

## Manual follow-ups

1. **Re-tune `timeoutMs` if it was inflated to absorb connect time.** The streaming budget is now
   measured from run start. A project that raised `timeoutMs` to compensate for slow delegate
   connects can lower it back; a project that relied on the (buggy) combined budget effectively
   gets more generous delegate deadlines now.
2. **Startup-time construction errors.** If any wiring constructed a tool without a state schema
   and only "worked" because the tool was never invoked, it will now throw at construction. The
   fix is to pass `stateSchema` (or delete the dead tool).
